Drop your certificate image files in this folder (e.g. `postman-api.jpg`,
`cypress-course.png`), then add an entry in `src/data/certificates.js`
with four fields: `title`, `organization`, `url` (where the card should
link to), and `image` set to `/certificates/your-file.jpg`.

This README also keeps the folder tracked in git even if it were ever
empty (git doesn't track empty folders) — feel free to delete it, it's
just documentation.
